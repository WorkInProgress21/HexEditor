A simple Hex viewer, that runs inb the Console/Terminal. 

How to run:
Doubleclick the .exe after downloading the Build to run.

How to use:
First specify the amount of columns you want as a whole number. Be aware that this feature is pretty janky. Then provide the absolute path to the File you want to view. Either one of these formats are fine: "C:/Users/user/" "C:\Users\user\"
